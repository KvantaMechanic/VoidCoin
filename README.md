# VoidCoin Core v2.0.3

### Because apparently somebody has to preserve this thing.

This repository contains the recovered **VoidCoin Core v2.0.3** source code, preserved for historical reference and anyone brave enough to attempt restoring the original VoidCoin blockchain.

**v1.0.5 was NOT the final release.** VoidCoin underwent numerous updates, including consensus changes and hard forks, before development was abandoned.

**If you're attempting to revive VoidCoin, start here.**

## Important

- **This is NOT a new cryptocurrency or chain launch.**
- v2.0.3 is a later release than the commonly preserved v1.0.5.
- Earlier versions may follow incompatible blockchain histories.
- Verify historical block hashes and consensus rules against surviving nodes before declaring any recovered chain canonical.
- Existing wallet files and historical balances should be preserved.
- Do not assume that successfully syncing from genesis means you've recovered the correct chain.
- **Certain files are granted a single use license for "Void Coin Core v2.0.3" ONLY, so that any users with coins locked in Vaults can retrieve them**

**A blockchain's history doesn't become canonical simply because somebody started mining it again.**
